# Actores del Sistema

## Marketplace E-commerce

| Actor | ¿Qué necesita realizar? |
|---|---|
| Cliente | Buscar productos, consultar información, agregar productos al carrito, realizar pedidos, efectuar pagos y consultar el estado de sus compras. |
| Vendedor | Registrar productos, actualizar información, gestionar precios y stock, consultar pedidos y revisar las ventas realizadas. |
| Administrador | Gestionar usuarios, vendedores, productos, categorías, pedidos y controlar el funcionamiento general de la plataforma. |
| Pasarela de pago | Procesar los pagos realizados por los clientes y comunicar el resultado de cada transacción. |
| Servicio de envío | Gestionar la información relacionada con la entrega y el seguimiento de los pedidos. |
| Servicio de facturación | Generar comprobantes de pago correspondientes a las compras realizadas. |
| ERP | Proporcionar o sincronizar información relacionada con productos, inventario y stock. |
