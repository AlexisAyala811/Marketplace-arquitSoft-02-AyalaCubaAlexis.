# Marketplace - Arquitectura de Software

Este repositorio contiene el análisis, la arquitectura y el diseño del sistema marketplace, junto con un boilerplate de implementación.

## Estructura del proyecto

```text
docs/
├── 01-analisis-de-sistema/
├── 02-arquitectura-software/
├── 03-diseño-de-software/
└── 04-modelo-c4/
img/
└── .gitkeep
tecnologia/
└── boilerplate-clean-arquitecture/
```

Los documentos existentes se conservaron y los archivos pendientes quedaron creados para completarse más adelante.

## Objetivo

Documentar el contexto del sistema, sus requisitos y los atributos de calidad que orientan la arquitectura del marketplace, además de registrar sus decisiones, diseño y modelo C4.
