# Marketplace - Arquitectura de Software

Este repositorio contiene el análisis y la propuesta inicial de arquitectura para el proyecto de marketplace.

## Estructura del proyecto

- `analisis-del-sistema/`: documentación de actores, historias de usuario, requisitos y restricciones.
- `arquitectura/`: propuesta inicial de arquitectura.

## Contenido

1. Análisis del sistema
2. Definición de requisitos y drivers arquitectónicos
3. Propuesta de arquitectura inicial

---

## Objetivo

Documentar el contexto del sistema, los actores involucrados, los requisitos funcionales y no funcionales, así como los principales drivers que orientan la arquitectura del marketplace.
