# Historias de Usuario

## Marketplace E-commerce

| ID | Historia de usuario |
|---|---|
| HU01 | Como cliente, quiero buscar productos, para encontrar los artículos que necesito. |
| HU02 | Como cliente, quiero consultar la información de un producto, para conocer su precio, descripción y disponibilidad antes de comprarlo. |
| HU03 | Como cliente, quiero agregar productos al carrito, para preparar los productos que deseo comprar. |
| HU04 | Como cliente, quiero modificar o eliminar productos del carrito, para gestionar los artículos antes de confirmar mi compra. |
| HU05 | Como cliente, quiero realizar un pedido con los productos de mi carrito, para completar mi compra. |
| HU06 | Como cliente, quiero realizar el pago de mi pedido, para confirmar la compra de los productos seleccionados. |
| HU07 | Como cliente, quiero consultar mis pedidos y su estado, para conocer el avance de mis compras. |
| HU08 | Como cliente, quiero registrar una dirección de entrega, para recibir mis pedidos en la ubicación indicada. |
| HU09 | Como vendedor, quiero registrar productos, para ofrecerlos a los clientes dentro del marketplace. |
| HU10 | Como vendedor, quiero actualizar la información de mis productos, para mantener actualizados sus precios, descripciones y disponibilidad. |
| HU11 | Como vendedor, quiero gestionar el stock de mis productos, para controlar la cantidad disponible para la venta. |
| HU12 | Como vendedor, quiero consultar los pedidos relacionados con mis productos, para gestionar las ventas realizadas. |
| HU13 | Como vendedor, quiero consultar mis ventas, para llevar un control de las operaciones realizadas en la plataforma. |
| HU14 | Como administrador, quiero gestionar los vendedores registrados, para controlar quiénes pueden ofrecer productos en el marketplace. |
| HU15 | Como administrador, quiero gestionar los usuarios de la plataforma, para controlar su acceso al sistema. |
| HU16 | Como administrador, quiero gestionar las categorías de productos, para mantener organizado el catálogo del marketplace. |
| HU17 | Como administrador, quiero supervisar los productos publicados, para controlar la información disponible en la plataforma. |
| HU18 | Como administrador, quiero consultar los pedidos realizados, para supervisar las operaciones del marketplace.
