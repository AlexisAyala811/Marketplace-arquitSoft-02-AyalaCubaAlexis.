# 02. Historias de usuario

## Introducción

Las historias de usuario describen las necesidades del negocio desde la perspectiva del usuario final.

## Historias principales

### HU-01: Registro de usuario
Como comprador o vendedor, quiero registrarme en la plataforma para crear mi cuenta y acceder a las funcionalidades del marketplace.

### HU-02: Publicación de producto
Como vendedor, quiero publicar un producto con descripción, precio e imágenes para mostrarlo a los compradores.

### HU-03: Búsqueda de productos
Como comprador, quiero buscar productos por categorías o palabras clave para encontrar opciones relevantes.

### HU-04: Compra de producto
Como comprador, quiero comprar un producto de forma segura y rápida para completar mi pedido.

### HU-05: Gestión de pedidos
Como vendedor, quiero ver y gestionar pedidos para atender correctamente las solicitudes de los clientes.

### HU-06: Administración del sistema
Como administrador, quiero supervisar usuarios, productos y transacciones para mantener el marketplace funcionando correctamente.
