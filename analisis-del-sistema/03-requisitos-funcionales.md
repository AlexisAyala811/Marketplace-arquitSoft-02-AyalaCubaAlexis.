# 03. Requisitos funcionales

## Objetivo

Definir las capacidades que debe ofrecer el sistema para cumplir con la operación del marketplace.

## Requisitos funcionales

1. El sistema debe permitir el registro e inicio de sesión de usuarios.
2. Los vendedores deben poder publicar productos con información detallada.
3. Los compradores deben poder buscar y filtrar productos.
4. El sistema debe permitir la creación y gestión de pedidos.
5. El sistema debe soportar pagos o simulación de pagos.
6. El sistema debe mostrar el estado del pedido al comprador y al vendedor.
7. El administrador debe poder gestionar usuarios, productos y operaciones.
8. El sistema debe enviar notificaciones básicas sobre cambios importantes.

## Prioridad

Los requisitos anteriores se consideran funcionales esenciales para la operación inicial del marketplace.
