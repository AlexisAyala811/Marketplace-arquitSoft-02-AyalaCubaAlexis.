# Requisitos Funcionales

## Marketplace E-commerce

| ID | Requisito funcional |
|---|---|
| RF01 | El sistema debe permitir buscar productos mediante palabras clave, categorías o criterios de búsqueda. |
| RF02 | El sistema debe permitir consultar la información detallada de los productos, incluyendo precio, descripción y disponibilidad. |
| RF03 | El sistema debe permitir agregar productos al carrito de compra. |
| RF04 | El sistema debe permitir modificar la cantidad o eliminar productos del carrito de compra. |
| RF05 | El sistema debe permitir generar un pedido a partir de los productos seleccionados en el carrito. |
| RF06 | El sistema debe permitir procesar el pago de los pedidos mediante una pasarela de pago externa. |
| RF07 | El sistema debe permitir consultar los pedidos realizados y su estado. |
| RF08 | El sistema debe permitir registrar y actualizar direcciones de entrega del cliente. |
| RF09 | El sistema debe permitir al vendedor registrar nuevos productos en el marketplace. |
| RF10 | El sistema debe permitir al vendedor actualizar la información de sus productos. |
| RF11 | El sistema debe permitir gestionar el stock disponible de los productos. |
| RF12 | El sistema debe permitir al vendedor consultar los pedidos relacionados con sus productos. |
| RF13 | El sistema debe permitir al vendedor consultar el historial de ventas realizadas. |
| RF14 | El sistema debe permitir al administrador registrar, actualizar, aprobar o desactivar vendedores. |
| RF15 | El sistema debe permitir al administrador gestionar los usuarios de la plataforma. |
| RF16 | El sistema debe permitir crear, actualizar y eliminar categorías de productos. |
| RF17 | El sistema debe permitir al administrador consultar y supervisar los productos publicados. |
| RF18 | El sistema debe permitir al administrador consultar los pedidos realizados en el marketplace. |
| RF19 | El sistema debe permitir generar comprobantes de pago de las compras realizadas. |
| RF20 | El sistema debe permitir enviar la información de los pedidos al servicio de envío para gestionar la entrega. |
